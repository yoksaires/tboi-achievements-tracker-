# Isaac Progress — сайт достижений

## Что работает

- каталог всех 641 достижений;
- поиск, фильтры по статусу, изданию и типу;
- карточки с русским и английским названием, иконкой и условием;
- кликабельные ссылки и встроенные иконки внутри условий;
- локальный разбор `persistentgamedata*.dat`;
- отображение открытых/закрытых достижений;
- прогресс по каждому изданию;
- автоматическое сохранение извлечённого списка достижений в `localStorage`;
- Steam-кнопка оставлена как функция в разработке.

## Данные

- `data/achievements.json` — облегчённая база, используемая сайтом;
- `data/achievements-full.json` — полная база с дополнительными полями;
- `data/achievements-data.js` — та же облегчённая база в виде JS, чтобы сайт работал даже при открытии через `file://`.

Тексты и изображения получены из русской The Binding of Isaac Wiki на Fandom и требуют атрибуции по CC BY-SA.

## Приватность

Файл сохранения читается через браузерный File API и не отправляется в сеть. В браузере сохраняются только номера открытых достижений и имя выбранного файла.
